## 🔧 Replit Setup Instructions

### Step 1: Import Project
1. Fork or import the repository: `https://github.com/CreoDAMO/SpiralParserEngine`
2. Wait for the import to complete (this may take 2-3 minutes due to large dependencies)

### Step 2: Alternative Manual Setup (If Import Fails)
If direct import doesn't work, you can set up the project manually:

1. **Create New Replit**: Start with a Node.js template
2. **Clone Repository**: Use the terminal to clone the source code
3. **Install Dependencies**: Run `npm install` to set up all required packages
4. **Configure Environment**: Create `.env.local` with required API keys

### Step 3: Environment Configuration
Create a `.env.local` file in the root directory with the following variables:

```bash
# Database Configuration (Required)
DATABASE_URL="your_neon_postgresql_url"
DIRECT_URL="your_neon_direct_url"

# AI Model API Keys (Optional - for full AI features)
OPENAI_API_KEY="your_openai_api_key"
ANTHROPIC_API_KEY="your_claude_api_key"
DEEPSEEK_API_KEY="your_deepseek_api_key"
GROK_API_KEY="your_grok_api_key"

# Blockchain Configuration (Optional - for blockchain features)
HYBRID_NETWORK_RPC="your_hybrid_rpc_endpoint"
PRIVATE_KEY="your_wallet_private_key"

# Quantum Computing (Optional - for quantum features)
QUANTUM_PROVIDER="your_quantum_provider"
QUANTUM_TOKEN="your_quantum_access_token"

# Session Security (Required)
SESSION_SECRET="your_random_session_secret_here"

# Development Mode
NODE_ENV="development"
NEXT_PUBLIC_BASE_URL="https://your-repl-name.your-username.repl.co"
```

### Step 4: Database Setup
1. **Create Neon Database**: Sign up at https://neon.tech
2. **Get Connection String**: Copy DATABASE_URL from Neon dashboard
3. **Run Migrations**: Execute `npm run db:migrate` to set up database schema

### Step 5: Start Development Server
```bash
npm run dev
```

The server will start on port 3000. You can access the IDE at your Replit URL.

### Step 6: Troubleshooting Common Issues

#### Port Configuration
- The app runs on port 3000 by default
- If port 3000 is occupied, Next.js will automatically use the next available port
- Replit will expose the port automatically

#### Missing Dependencies
If you encounter module errors:
```bash
npm install
# or if that fails:
npm ci
```

#### Database Connection Issues
- Ensure DATABASE_URL is correctly set in `.env.local`
- Verify your Neon database is active and accessible
- Check that the connection string includes the correct credentials

#### Grammar Compilation (Optional)
The project includes SpiralScript grammar files. To regenerate them:
```bash
npm run compile:grammar
npm run generate:languages
```
